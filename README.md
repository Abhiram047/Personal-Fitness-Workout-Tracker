 # Personal Fitness & Workout Tracker

A simple Java console-based application for tracking daily workouts, calories burned, fitness goals, and BMI.

## About the Project

The Personal Fitness & Workout Tracker allows users to set a daily calorie goal, record multiple workouts, calculate total calories burned, check goal achievement, and calculate BMI with its category.

## Features

- Set daily calorie goal
- Add multiple workouts
- Calculate total calories burned
- Check daily goal achievement
- Calculate BMI
- Display BMI category
- Display a 7-day workout report

## Java Concepts Used

- Scanner for user input
- Variables and data types
- While loop for adding multiple workouts
- If-else for checking the calorie goal
- Else-if for BMI categories
- For loop for the weekly report
- Arithmetic operations and formatted output
